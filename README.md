# homebrew-tap

Homebrew tap for [dkdc-io](https://github.com/dkdc-io) packages.

## Usage

```bash
brew tap dkdc-io/tap
brew install <formula>
```

## Formulae

- `zorto`: the AI-native static site generator with executable code blocks ([zorto.dev](https://zorto.dev))

```bash
brew install dkdc-io/tap/zorto
```
